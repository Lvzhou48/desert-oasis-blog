最近体验 DeepSeek Harness 时，有一个设计让我印象很深：Everything is a Plugin。

模型、工具、工作流和界面都可以通过插件扩展。虽然它目前还处于早期阶段，也不一定会成为通用 Agent 赛道最后的第一名，但这种插件模式让我看到了一种很有可能属于 Agent 的未来。

## Agent 世界里的“创意工坊”

这让我想到了 Steam。

一些游戏能够长期保持生命力，除了游戏本身足够优秀，也离不开创意工坊。玩家会制作新的地图、角色、玩法和各种 Mod。一款原本由开发团队维护的游戏，慢慢变成了由官方、创作者和玩家共同参与的生态。

DeepSeek Harness 的插件模式也有些类似。

官方提供基础框架，社区则围绕不同需求增加工具和工作流。对于动手能力强的人来说，不必从头开发一个完整的 Agent，也不用等待官方增加某项功能，只需要围绕一个具体问题做出插件，就能加入这个生态。

未来通用 Agent 之间的竞争，可能不只是比较模型能力，也要看谁能让插件更容易开发、安装和组合，谁能建立起更活跃、更可靠的社区。

真正形成壁垒的，未必是某一个功能，而可能是整个生态创造新能力的速度。

## 当我的想法已经被别人做出来了

看到 DeepSeek Harness 可以制作插件后，我很快有了好几个想法。

但真正去寻找时，我发现不少想法已经有人做了，而且完成度还不错。

这种感觉有一点失落，但更多的是惊讶和兴奋。

现在真正深入接触大模型和 Agent 的人可能还不算多，但其中已经有一批年轻的开发者和创作者，不满足于把 AI 当成聊天工具。他们会拆解它、改造它，为它增加新的能力，然后分享给其他人。

这也让我意识到，“有人已经做了”并不代表自己没有机会。

现有插件可能还可以改进，分散的能力可能还缺少组合方式，一些通用方案也可能没有覆盖具体人群的真实需求。

所以以后再有一个插件想法时，我不想只问“有没有人做过”，还想继续问：

> 它有没有解决一个足够具体的问题？  
> 现有方案还有哪里没有做好？  
> 我能不能让它更可靠、更易用？

DeepSeek Harness 最终会走到哪里，我不知道。

但我越来越相信，未来的通用 Agent 不会只是一个由官方定义好、用户被动使用的产品。它更可能像一个平台：官方搭起框架，社区不断增加新的能力，用户也参与塑造它最终长成什么样子。

今天这些还很早期的插件，或许就是 Agent 时代最早的一批 Mod。

而我们现在看到的，也许正是“Agent 创意工坊”开始形成的时刻。
